Mall of Cayman - Feature Documentation
====================================

User Roles
----------
- Admin: Platform owner/staff with full access.
- Seller (Vendor): Shop owners who sell products.
- Customer/User: Shoppers/buyers.
- Store Manager: Manages a seller’s shop (optional, paid service).

1. User Management
------------------
| Feature                      | Used By         | Description |
|------------------------------|-----------------|-------------|
| User Registration/Login      | Customer        | Sign up, activate via email, login/logout, password reset. |
| Seller Registration/Login    | Seller          | Register shop, upload trade license, activate via email, login/logout, password reset. |
| Admin User Management        | Admin           | Create, edit, delete users (Admin, SubAdmin, Manager, Seller, Customer). |
| Role Assignment/Change       | Admin           | Change user roles, promote/demote users, assign permissions. |
| Ban/Unban Users              | Admin           | Temporarily disable user accounts. |
| Profile Management           | All             | Update profile info, avatar, addresses, password. |
| Store Manager Service        | Seller, Manager | Sellers can request a store manager; managers can be assigned to shops. |

2. Product Management
----------------------
| Feature                      | Used By         | Description |
|------------------------------|-----------------|-------------|
| Product Creation/Editing     | Seller, Manager, Admin | Add/edit products, upload images/videos, set attributes, manage inventory. |
| Product Approval Workflow    | Admin           | Approve/reject seller products before they go live. |
| Product Deletion             | Seller, Manager, Admin | Remove products from shop/platform. |
| Product Reviews              | Customer        | Leave reviews/ratings for purchased products. |
| Product Search & Listing     | All             | Browse/search products, filter by category, shop, etc. |
| Product Variations           | Seller, Manager | Add size, color, and other variations. |

3. Shop & Seller Management
---------------------------
| Feature                      | Used By         | Description |
|------------------------------|-----------------|-------------|

| Shop Approval Workflow       | Admin           | Approve/reject new shops, manage seller status. |

| Shop Deletion                | Admin           | Remove shops and all associated data. |
| Shop Listing                 | All             | View all approved shops, featured stores, shop details. |

12. Frontend Page Mapping (Key Routes)
---------------------------------------
- Customer/User: Home, Products, Product Details, Cart, Checkout, Orders, Profile, Inbox, Video Calls, Blog, FAQ, Policies, Contact.
- Seller: Shop Dashboard, Product/Event/Order/Refund/Ad Management, Settings, Video Calls, Store Manager, Subscription, Analytics.
- Admin: Admin Dashboard, Users, Sellers, Orders, Products, Events, Withdrawals, Banners, Categories, Staff, Analytics, Subscriptions, Reviews, Ads, Plans, Legal, FAQ, Site Settings.
- Store Manager: Dashboard, Products, Orders, Ads, Inventory, Analytics for assigned shop.

13. Key Workflow Examples
-------------------------
- Seller Onboarding: Register shop → Upload documents → Email activation → Admin approval → Access dashboard.
- Product Lifecycle: Seller/Manager creates product → Admin approves → Product visible to customers.
- Order Flow: Customer places order → Seller/Manager processes → Status updates → Delivery/refund as needed.
- Ad Purchase: Seller/Manager selects ad type/slot → Uploads creative → Pays (if required) → Admin approval → Ad goes live.
- Subscription: Seller selects plan → Pays via PayPal → Features unlocked as per plan.
